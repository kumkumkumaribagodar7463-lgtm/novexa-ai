# NOVEXA AI — Complete Launch Starter
Frontend + admin dashboard + auth/API structure + Prisma/PostgreSQL schema + SEO/deployment files.

## Run locally
Node.js 20+
1. npm install
2. Copy .env.example to .env
3. Configure DATABASE_URL and production provider secrets
4. npx prisma generate
5. npm run dev

## Production
OTP delivery, AI provider, payment gateway, production database/storage, CAPTCHA and rate limiting need real provider credentials/configuration.
Never share passwords, OTPs or secret API keys.
